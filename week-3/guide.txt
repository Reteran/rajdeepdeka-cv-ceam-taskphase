Key Technical Concepts
Feature Detection & Description (ORB / SIFT):   
PNG

SIFT (Scale-Invariant Feature Transform): Detects scale- and rotation-invariant keypoints using difference-of-gaussians and generates robust gradient-based descriptors.

ORB (Oriented FAST and Rotated BRIEF): A faster, rotation-aware, and scale-space-tolerant binary feature detector well-suited for real-time edge applications.

Feature Matching & Verification:   
PNG

Establish correspondence between key points across consecutive video frames using distance metrics (e.g., Hamming distance for ORB, L2 norm for SIFT).

Apply filtering techniques like Lowe's ratio test or RANSAC to eliminate outlier matches and erroneous vectors.

Lucas-Kanade Optical Flow:   
PNG

Compute sparse optical flow to track movement vectors of localized feature points under the assumption of constant pixel intensity in a local neighborhood.
